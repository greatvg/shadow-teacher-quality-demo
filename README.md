# 影子老师质量监督演示版

面向特殊儿童校内支持场景的服务质量评估与专业信用体系演示版。

## 在线体验

https://greatvg.github.io/shadow-teacher-quality-demo/

## 核心流程

- 家长比较影子老师的认证、毕业案例、督导时长和价格。
- 影子老师逐课提交反馈，校内老师轻量核验，家长查看当天时间轴。
- 毕业提名依次经过心理观察、平台督导审核和家长确认，并计入老师专业信用。
- 四类角色可切换浏览，模拟状态保存在浏览器本地。
- 体验反馈与演示业务数据分开保存，可导出 JSON。

所有人物、儿童与课堂记录均为虚构演示数据，不包含真实个人信息。
