# 融合教育数字化智能工具演示版

## 运行方式

该演示版不依赖构建工具。使用本地静态服务器打开 `index.html` 即可。

## 演示角色

- 家长端：比较老师、查看每日时间轴、查看成长档案并确认毕业结果。
- 影子老师端：管理学期课表与干预计划、填写分色逐课总结、查看专业信用并发起毕业提名。
- 校内老师端：轻量确认反馈是否属实，可填写评语或退回修正。
- 专业审核端：完成心理观察、平台督导审核和老师认证待办。

## 影子老师端近期改进

- 学期课表以表格呈现，上传后自动数字化，一学期一更新。
- 每日课程可修改名称，例如雨天把体育课备注为语文课，不影响学期课表。
- 学期干预计划按月展示干预重点，老师端可编辑，家长端同步查看。
- 每节课后总结分为社交情况、学习习惯、情绪控制三类，绿色/蓝色表示进步，红色表示需关注。

在线 AI 督导的长期架构规划见 [AI_SUPERVISION_ARCHITECTURE.md](AI_SUPERVISION_ARCHITECTURE.md)。

## 联动流程

1. 影子老师端在“今日课表”填写数学课反馈。
2. 切换校内老师端，在“待我确认”确认该反馈。
3. 切换家长端，在“孩子今日”查看已核验记录。
4. 影子老师端在“专业信用”发起毕业提名。
5. 专业审核端在“毕业认证”依次完成心理观察和督导审核。
6. 家长端在“成长档案”确认毕业，老师毕业案例数随之增加。

所有数据均为虚构演示数据，浏览器本地保存，可通过左侧“重置演示数据”恢复。

## 收集体验反馈

桌面端使用左侧“体验反馈”，移动端使用右下角铅笔按钮。反馈会自动记录当前角色、页面和提交时间，并与演示业务数据分开保存在浏览器中；重置演示数据不会删除反馈。

提交至少一条反馈后，再次打开反馈窗口即可导出 JSON 文件。第二阶段将以导出的反馈清单为依据调整范围与优先级。
